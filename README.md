# 🛒 NIV Kirana

> **Smart Digital Kirana & Khata Commerce Platform**  
> Built with **React Native (Expo SDK 57)** and **Supabase Cloud Backend**.

---

## 🌟 Key Features

- **Customer Store**: Browse categories, daily deals, voice ordering, and festival baskets.
- **Universal Scanner**: Real-time camera scanner for barcodes & QR product lookups.
- **Khata Credit Ledger**: Digital ledger for credit balance and transaction history.
- **Store Admin Console**: Orders queue, live catalog management, restock controls, and customer approvals.
- **Cloud Sync**: Real-time Supabase cloud integration with local storage fallback.

## 🚀 Getting Started

### 1. Installation
```bash
# Install dependencies
pnpm install
```

### 2. Environment Configuration
Create a `.env` file based on `.env.example`:
```env
EXPO_PUBLIC_SUPABASE_URL=your_supabase_url
EXPO_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 3. Start Development Server
```bash
# Start Metro bundler (Expo Go / Web)
npx expo start
```
Scan the terminal QR code using **Expo Go** on Android/iOS, or press `w` to launch the web version.
